Het vlak waarin Claude Code draait, met dezelfde grond als de rest van het venster.

**Status:** gekozen op het keuzebord.

De inhoud komt van Claude Code zelf. De app bepaalt alleen de letter, de grond en de kleuren.

- Letter `terminal`, op `bg`, met `tab-pad` marge links en rechts.
- Gedempte regels in `mute`, een geslaagde stap met een bolletje in `term-green`, de bezig-regel in `term-accent`.
- Een diff kleurt de hele regel: `term-del` voor weg, `term-add` voor erbij, met tekst in `ink`.
- Het invoerveld heeft een rand in `line-strong`, hoogte `h-invoer` en rechte hoeken.
- Een pad in de terminal is aan te klikken en opent het bestand.
