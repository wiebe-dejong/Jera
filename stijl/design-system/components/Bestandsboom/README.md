De mappen en bestanden van het project in de linkerkolom.

**Status:** gekozen op 14 november 2026.

Geef de boom, welke mappen open staan en welk bestand gekozen is.

- Elke regel is `h-rij` hoog. Een niveau dieper springt `inspring` in.
- Een map heeft een pijltje en een naam die op `/` eindigt, met rechts een plusteken om daar een sessie te starten.
- Een bestand heeft geen icoon.
- Een klik op een bestand opent het in de app die macOS ervoor heeft.
- Een map wordt pas gelezen als hij opengaat.
