Een tab per git-repo, in de titelbalk naast de vensterknoppen.

**Status:** gekozen op het keuzebord.

Geef per tab de naam van de repo en het aantal sessies. Eén tab is actief.

- De actieve tab heeft de grond `bg`, vette tekst en een streep van `streep` in `accent` erboven.
- Een niet-actieve tab is `mute` op `bar`, met een lijn van `line` links.
- Na de laatste tab staat een plusteken om een map toe te voegen.
- Helemaal rechts staat de knop voor het paneel van de hele computer, met de aantallen poorten en agent-browsers.
- Toon geen status in de tab. De status staat in de sessielijst.
