Eén regel per sessie: het statusicoon en de titel die Claude Code aan de sessie geeft.

**Status:** gekozen op het keuzebord.

Geef per sessie de status en de titel, en per groep de naam van de map.

- Het icoon staat voor de titel, met `gap` ertussen. Er staat geen statuswoord in de regel.
- De gekozen sessie heeft het vlak `sel`, vette tekst en een streep van `streep` in `accent` links.
- Een idle sessie heeft een titel in `mute`.
- Een te lange titel wordt afgekapt met een beletselteken.
- Boven elke groep staat de map in `mute`, met rechts een plusteken om daar een sessie te starten.
- Elke regel is `h-rij` hoog. Maak geen regel van twee regels tekst.
